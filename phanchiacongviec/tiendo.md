Giai đoạn 1: Khởi tạo và Nền tảng (Ngày 1 - 3)Mục tiêu: Dựng bộ khung cơ bản, thiết lập kết nối mạng và thống nhất cấu trúc dữ liệu.Ngày 1: Thiết kế kiến trúc & Setup môi trườngCả nhóm: Khởi tạo repository Git. Thống nhất cấu trúc thư mục, chuẩn code C++. Thiết kế định dạng gói tin TCP và Custom UDP Header (Sequence no, ACK, Flags).  Ngày 2 - 3: Lập trình Socket cơ bảnDev 1: Dựng TCP Server Socket, lắng nghe kết nối và xử lý luồng xác thực cơ bản (USER, PASS, QUIT).  Dev 2: Dựng UDP Client/Server Socket, gửi nhận gói tin thô thành công. Bắt đầu đưa Custom UDP Header vào bản tin.  Dev 3: Xây dựng khung giao diện Client CLI. Dựng kiến trúc Multi-threading (hoặc Multi-processing) trên Server để sẵn sàng đón nhiều Client.  Giai đoạn 2: Xây dựng Core Logic (Ngày 4 - 7)Mục tiêu: Hoàn thiện kênh điều khiển TCP, xử lý File và phần khó nhất là giao thức truyền tải tin cậy (RDT) qua UDP.Ngày 4 - 5: Phát triển lệnh điều khiển & Chế độ truyềnDev 1: Code bộ phân tích cú pháp (Parser) và logic cho các lệnh thao tác thư mục (PWD, CWD, LIST, MKD...). Cài đặt hệ thống mã phản hồi chuẩn 1xx-5xx qua TCP.  Dev 3: Cài đặt logic chuyển đổi Active/Passive mode (PORT, PASV). Xây dựng các hàm I/O đọc/ghi file nhị phân (binary) và văn bản (ASCII).  Ngày 6 - 7: Chế tạo RDT (Reliable Data Transfer) - Sprint quan trọngDev 2: Lập trình cơ chế RDT bằng C++: Xử lý Timeout, Retransmit, gửi nhận ACK theo mô hình Stop-and-Wait hoặc Go-Back-N/Selective Repeat.  Dev 1 & 3: Hỗ trợ Dev 2 debug mạng. Dev 3 bắt đầu code tích hợp hàm băm HASH (MD5/SHA-256) để chuẩn bị kiểm tra tính toàn vẹn.  Giai đoạn 3: Tích hợp hệ thống & Kiểm thử (Ngày 8 - 10)Mục tiêu: Ghép nối Control Channel (TCP) và Data Channel (UDP) để chạy luồng upload/download hoàn chỉnh.Ngày 8: Ghép nối & Xử lý Upload/DownloadCả nhóm: Tích hợp luồng lệnh RETR (tải xuống) và STOR (tải lên). Khi Client gửi lệnh qua TCP, Server mở kết nối UDP, sử dụng RDT của Dev 2 để truyền file, và Dev 3 đảm bảo ghi file an toàn, kiểm tra HASH.  Ngày 9: Tối ưu & Nâng cao (Excellent Level)Dev 2: Thêm kiểm soát luồng/tắc nghẽn (Sliding Window) vào giao thức UDP tự chế.  Dev 1 & 3: Xử lý các edge cases (ngắt kết nối đột ngột với lệnh ABOR, xử lý trùng tên file với STOU).  Ngày 10: Bug fixing & Bắt đầu làm Báo cáoCả nhóm: Đóng băng tính năng mới (Code Freeze). Chạy thử nghiệm trên nhiều máy khác nhau để đảm bảo code compile và chạy mượt trên "clean machine". Chụp ảnh màn hình các phiên truyền file thành công.  Giai đoạn 4: Tài liệu hóa & Luyện tập bảo vệ (Ngày 11 - 12)Mục tiêu: Hoàn thiện Technical Report và diễn tập Live Coding.Ngày 11: Viết Technical ReportDev 1: Vẽ Sequence diagram cho vòng đời TCP + UDP.  Dev 2: Viết mô tả cấu trúc Header, vẽ Flowchart cho state machines của RDT Sender/Receiver.  Dev 3: Hoàn thiện sơ đồ Active/Passive và Thread-dispatch.  Cả nhóm: Bổ sung Phụ lục GenAI (ghi rõ Prompt, Code AI, và cách mình đã debug/tối ưu). Lập bảng chia % đóng góp.  Ngày 12: Diễn tập Oral Defense & Live CodingCả nhóm: Đặt câu hỏi vấn đáp chéo cho nhau. Đảm bảo Dev 1 hiểu TCP, Dev 2 nắm vững từng byte của UDP header và các trạng thái RDT, Dev 3 giải thích được đa luồng.  Tập mô phỏng việc giảng viên yêu cầu sửa lỗi (Live debugging) hoặc thay đổi một đoạn code mạng ngay tại chỗ.
