## 7.1 Tổng quan các ca kiểm thử

Hybrid FTP cần thể hiện **7 ca kiểm thử chính** để chứng minh toàn bộ tính năng:

| STT | Ca kiểm thử | Mục đích | Evidence cần |
| :---: | :--- | :--- | :--- |
| 1 | **Upload file thành công** | Chứng minh STOR + RDT + file write | Screenshot + log server + file received |
| 2 | **Download file thành công** | Chứng minh RETR + RDT + file send | Screenshot + log server + file size match |
| 3 | **So sánh mã băm SHA-256** | Chứng minh độ toàn vẹn file (kiểm tra data không bị hỏng) | Mã băm trước/sau transfer khớp nhau (100%) |
| 4 | **Danh sách phiên client** | Chứng minh multi-threading + session management | Bảng liệt kê IP/Port/Status client đang kết nối |
| 5 | **Multiple concurrent clients** | Chứng minh server xử lý nhiều client đồng thời | Log thể hiện 3+ client cùng upload/download |
| 6 | **Transfer file ASCII** | Chứng minh hỗ trợ TYPE A (text mode) | Log + file nội dung so sánh |
| 7 | **Transfer file Binary** | Chứng minh hỗ trợ TYPE I (binary mode) | Log + file binary size khớp |

## 7.7 Ca Kiểm Thử 5: Multiple Concurrent Clients Downloading

### Mục đích
Chứng minh:
- Server xử lý 3+ clients cùng lúc
- Mỗi thread độc lập, không ảnh hưởng nhau
- RDT hoạt động stable với multiple sessions

### ⚠️ Lưu ý quan trọng trước khi chạy

> **Server storage:** Server tìm thư mục `server_storage/` **tương đối từ thư mục hiện tại** khi khởi chạy.
> Vì vậy **phải `cd` vào root của project** trước khi chạy `./build/ftp_server`.
>
> **Server port:** Binary nhận port qua đối số CLI: `./build/ftp_server 2121`.
> Chạy **không có đối số** sẽ bind port 0 và exit ngay (không dùng được).
>
> **Client:** Binary `ftp_client` nhận `host port` qua đối số CLI.
> Lệnh FTP được đọc từ **stdin** — dùng `printf "...\r\n" | ./build/ftp_client 127.0.0.1 2121`
> để pipe lệnh vào. **Không có lệnh `open`** bên trong — kết nối thiết lập khi khởi chạy binary.
>
> **Thư mục download:** Mỗi client subshell nên `cd` vào thư mục riêng trước khi chạy
> để file download không bị ghi đè lẫn nhau.

**Bước 3 — Terminal 2: Chạy 3 clients đồng thời:**

Lưu nội dung sau thành `concurrent_download.sh` và chạy:

```bash
#!/bin/bash
# concurrent_download.sh — Test 7.7: Multiple Concurrent Clients Downloading

BUILD="/path/to/FTP_PROJECT/build"
CLIENT="$BUILD/ftp_client"

# Tạo thư mục riêng cho mỗi client nhận file
mkdir -p /tmp/client1_storage /tmp/client2_storage /tmp/client3_storage

echo "=== Starting concurrent download test ==="
echo "Timestamp: $(date '+%Y-%m-%d %H:%M:%S')"

# Client 1: Download file_A.bin (512KB)
(
  cd /tmp/client1_storage
  printf "USER user1\r\nPASS user1\r\nTYPE I\r\nPASV\r\nRETR file_A.bin\r\nQUIT\r\n" \
    | $CLIENT 127.0.0.1 2121
) > /tmp/client1_download.log 2>&1 &

# Client 2: Download file_B.bin (256KB)
(
  cd /tmp/client2_storage
  printf "USER user2\r\nPASS user2\r\nTYPE I\r\nPASV\r\nRETR file_B.bin\r\nQUIT\r\n" \
    | $CLIENT 127.0.0.1 2121
) > /tmp/client2_download.log 2>&1 &

# Client 3: Download file_C.bin (128KB)
(
  cd /tmp/client3_storage
  printf "USER user3\r\nPASS user3\r\nTYPE I\r\nPASV\r\nRETR file_C.bin\r\nQUIT\r\n" \
    | $CLIENT 127.0.0.1 2121
) > /tmp/client3_download.log 2>&1 &

# Chờ tất cả 3 clients hoàn thành
wait

echo ""
echo "=== DOWNLOAD RESULTS ==="
for i in 1 2 3; do
  if grep -q "226" /tmp/client${i}_download.log; then
    echo "✅ Client $i: Download SUCCESS"
  else
    echo "❌ Client $i: Download FAILED"
    echo "   Log: $(tail -5 /tmp/client${i}_download.log)"
  fi
done
```

```bash
echo ""

declare -A EXPECTED=([1]=524288 [2]=262144 [3]=131072)
echo "Client Results (file đã download):"
for i in 1 2 3; do
  FILE="/tmp/client${i}_storage/${FILES[$i]}"
  if grep -q "226" /tmp/client${i}_download.log; then
    SIZE=$(wc -c < "$FILE" 2>/dev/null || echo 0)
    if [ "$SIZE" -eq "${EXPECTED[$i]}" ]; then
      echo "✅ Client $i: ${FILES[$i]} — $SIZE bytes (CORRECT)"
    else
      echo "⚠️  Client $i: ${FILES[$i]} — $SIZE bytes (expected ${EXPECTED[$i]})"
    fi
  else
    echo "❌ Client $i: FAILED"
  fi
done
```
